# HackAssembler

Proyecto 3 de Organizacion de Computadores.

## Integrantes

- Eder Ceballos
- Isabela Ruiz de la Ossa

## Descripcion

Implementacion de un assembler y un disassembler para la plataforma Hack.

- El assembler convierte archivos `.asm` a `.hack`.
- El disassembler convierte archivos `.hack` a `.asm`.

## Estructura

- `docs/API.md`: documentacion de las clases y funcionamiento general.
- `docs/DESIGN.md`: diseno y diagrama textual de clases.
- `docs/USER_GUIDE.md`: instrucciones de compilacion, ejecucion y pruebas.
- `src/`: codigo fuente.
- `test/`: pruebas.
